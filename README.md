# ACHO WAFFLES website

A multi-page site for ACHO WAFFLES (Bhutan): Home, Our Story, Menu, Build your own, Gallery, Contact and Checkout.
All food pictures are real ACHO photographs (`img/`). Prices are in Nu. (Ngultrum).

It is plain static files, so it works on GitHub Pages or any static host. No build step is needed to run it.
React, react-dom and htm load from jsDelivr, and the fonts from Google Fonts.

## Things to fill in
Everything is in the `CONFIG` block at the top of `assets/site.js` and the `PRODUCTS` list just below it.

| What | Where |
| --- | --- |
| Real prices | `PRODUCTS` (price per item) and `BUILDER` in `assets/builder.js`. Then set `samplePrices: false` to hide the "sample prices" notes. |
| Opening hours | `hours` in `CONFIG` (currently placeholders) |
| WhatsApp number | `whatsapp` in `CONFIG` (currently 97577771913, assumed to be 77771913) |
| Payment QR and bank accounts | `payment.qrImage` (path to an image in `img/`) and `payment.accounts` in `CONFIG` |
| Delivery requests | `delivery: true/false` in `CONFIG` |
| Google Maps pin | `mapsLink` in `CONFIG` |

## How ordering and payment work
There is no card form: a static page cannot take card payments safely. At checkout the customer enters a name and phone,
chooses pickup or "ask about delivery", and chooses "pay when you collect" or "pay by QR or bank transfer".
The order is then sent by the customer on WhatsApp, with an order reference such as `ACHO-2211-K7QD`.
Nothing is confirmed or paid until the shop replies. The cart, favourites and saved customer details live in the visitor's
browser only (`localStorage`).

## Editing and tests
```
cd tools
npm install
npm run pages   # regenerate the HTML pages from tools/make_pages.py
npm run css     # recompile assets/site.css after changing classes (Tailwind 3.4)
npm test        # real-Chromium checks (Playwright 1.63): 274 checks, desktop and phone
```
`npm test` serves React and the fonts from `node_modules`, so it runs offline. It needs Playwright's Chromium (`npx playwright install chromium`).

## Layout
- `*.html` the seven pages (generated by `tools/make_pages.py`)
- `assets/site.js` shared code: settings, products, header, cart, quick view
- `assets/sections.js` page sections; `assets/builder.js` the waffle builder; `assets/checkout.js` the checkout
- `assets/site.css` compiled Tailwind plus custom styles (source: `tools/input.css`)
- `img/` photographs and the logo
